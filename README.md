# 平方根4択チャレンジ

平方根を一の位・桁数・およその大きさで絞り込む、全10問の静的Webアプリ。
`index.html` をブラウザーで開くだけで利用できます。外部ライブラリ・ビルド・通信・保存機能はありません。
GitHub Pagesでは対象ブランチの `/ (root)` を公開元に指定します。

## ファイル

- `index.html`: 問題・結果画面
- `styles.css`: レスポンシブな見た目
- `quiz.js`: 整数からの問題生成、選択肢の検証
- `app.js`: 回答、採点、画面遷移
- `tests/quiz.test.cjs`: 生成条件と再生成の検証（`node tests/quiz.test.cjs`）

## 生成規則

正の整数を抽選し、その整数同士の積を問題にします。平方根計算は使いません。
1〜2問目は32〜99、3〜5問目は100〜999、6〜8問目は1000〜9999、9〜10問目は10000〜99999です。
セット内と直前セットとの重複を避けます。

4択は正解1個、近い誤答1個、明らかな誤答2個です。
近い誤答は±10以内かつ差が正解の20%以内で、同じ桁数・2乗の一の位が一致する最も近い整数から抽選します。
明らかな誤答の1個は±4以内で2乗の一の位が不一致、もう1個は桁数違い・概数・最上位の数字の3タイプから抽選します。
後者は2乗の一の位を一致させ、大きさに目を向ける設計です。
概数で除外する数は正解の1.5倍以上または0.65倍以下とし、最上位タイプは同じ桁数かつ先頭数字も異なる条件を加えます。
2個の明らかな誤答を除外するための理由は問題ごとに組み合わせが変わります。

全候補の正整数・安全な整数範囲、重複なし、正解が唯一、全誤答の2乗が問題と異なること、近い誤答の条件、2個の明らかな誤答の除外条件を検証します。
不成立なら整数から抽選し直します（最大2000回、上限時はエラー表示）。選択肢はFisher–Yates法でシャッフルします。
最大の問題は99999²、誤答の2乗もJavaScriptで正確に扱える安全な整数範囲内です。
